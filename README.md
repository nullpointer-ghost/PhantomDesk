# PhantomDesk 🛡️ // Windows Privacy & System Optimization Suite

A lightweight, modern Windows utility built with Python and CustomTkinter. Cloak installed games and applications from Windows Control Panel/Settings, apply OS-level stealth attributes to files, and run batched system performance and privacy tweaks.

## 🚀 Key Features

- **App Cloaking Studio:** Mask installed games and software from Windows Control Panel & Settings without breaking save files or installations.
- **Batched Tweaks Hub:** 100+ Windows 11 de-bloat, privacy, gaming latency, and junk-cleaning tweaks split into lightweight batches with two-way reversibility.
- **Universal File Locker:** Apply system-level attributes (+h +s) to files/folders, take ownership, or break stuck file handles.
- **Zero-Byte Shredder:** Overwrite file sectors with random bytes before deletion to block file recovery.
- **Modern UI:** Tailwind/Zinc-inspired design with dark/light mode and full-screen support (F11).
